# Research log

One file per working day, `YYYY-MM-DD.md`. Written at the end of each session and pushed
the same day, so work can resume exactly where it stopped.

Each entry answers four things:

- **Did** — what was actually done, with numbers.
- **Found** — anything learned that changes the plan.
- **Decided** — choices made and why.
- **Next** — where to pick up.
